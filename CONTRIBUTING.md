# Contributing to DevShelf

1. Read [Setup](docs/SETUP.md) and [Architecture](docs/ARCHITECTURE.md).
2. Create a focused branch using the naming rules in [Engineering Workflow](docs/ENGINEERING_WORKFLOW.md).
3. Make the smallest complete change that satisfies the requirement.
4. Add or update tests from [Test Plan](docs/TEST_PLAN.md).
5. Run `npm test` and `npm run build` locally.
6. Open a pull request using the repository template.
7. Address review comments and keep the branch rebased or updated with the default branch.

Do not commit credentials, `.env` files, `node_modules`, build output, or real user data.
