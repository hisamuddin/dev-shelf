# DevShelf Component Reference

The table focuses on meaningful architectural components rather than every file.

| Name | Path | Type | Responsibility | Entry point | Dependencies | Dependents | Data access | External integrations | Configuration | Tests | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Client application | `client/src/main.jsx` | Frontend | Routes, pages, forms, resource cards, user/admin flows | `main.jsx` | React, React Router, Axios, Lucide, React Markdown | Browser users | Browser local storage and API | Local Express API | `VITE_API_BASE_URL`, `VITE_APP_NAME` | None currently | Single-file MVP composition; split into feature modules as it grows |
| Client styles | `client/src/styles.css` | Frontend design system | Responsive layout, theme tokens, states, dark mode | Imported by `main.jsx` | Browser CSS | All client views | None | None | CSS custom properties | None currently | Uses CSS tokens and responsive breakpoints |
| HTTP API | `server/src/index.js` | REST API | Middleware, response envelopes, routes, validation, workflow actions | `app.listen` in `index.js` | Express, Helmet, CORS, rate limit, Zod | Client and Postman consumers | `store`, `cache` | None configured | `PORT`, `CLIENT_URL`, `NODE_ENV` | Node test runner configured; no files | Controllers and application logic are still colocated; extraction is future work |
